App details

Offline & session status

Checking offline files…

Check offline files updates the status above. It checks cached application files; it does not repair the cache or test an offline relaunch. Test sound requests a tone; confirm it is audible on the intended output device.

Counting & controls

Counts scheduled metronome cues. Caller compressions and breaths are not detected. In 30:2 mode, click Resume compressions when the caller reports returning to compressions. The round advances on that click. Stop preserves the last display; a new Start resets the session.

Fresh launches are stopped, muted, 110 BPM, visual pulse on, and 30:2 mode. Only color and audio gain are saved. A breath phase never automatically restarts compressions. There are no global keyboard shortcuts; focused controls accept normal keyboard activation.

Safety & limitations

Unvalidated prototype. Follow your agency’s approved dispatch protocol. This does not measure compression depth, recoil, performed compressions, or delivered breaths. Mode selection requires clinical approval.

Stops after a detected timing interruption, when hidden, or on an audio-clock interruption. A frozen browser cannot immediately execute Stop or display a fault. Audio is scheduled at most 180 ms ahead; actual device buffering adds latency. The agency’s fallback procedure must remain usable without this page.

Two windows cannot start together when Web Locks is supported on the same browser profile and origin. Other profiles, browsers, origins, and devices remain independent. Use a single approved instance.

Installation & offline use

Serve this folder over HTTPS or localhost. Wait for Offline files verified, then test closing and reopening the installed app with the network disconnected. Browser storage can be cleared or evicted. Installation does not guarantee offline availability.

Stop the session before installing or applying an update. Clinical and workstation validation is required before operational use.
